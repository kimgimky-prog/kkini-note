# 끼니 노트

먹은 음식과 양을 적으면 오늘 부족한 영양소를 바로 보여주는 식단 기록 앱이에요.
폰에서 앱 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. 기록은 폰 안에만 저장돼요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `foods.js` | 음식 성분 목록 (100g당). 음식을 추가하려면 여기 |
| `nutrition.js` | 하루 목표 계산 (열량, 단백질 기준 등) |
| `style.css` | 색, 글꼴, 간격 |
| `index.html` | 화면 뼈대 |
| `app.js` | 버튼 동작, 저장, 화면 그리기 |
| `sw.js` | 인터넷 없이도 열리게 파일 보관. 파일을 고친 뒤 앱에 안 보이면 `VERSION` 숫자를 올리기 |
| `manifest.webmanifest` | 앱 이름·아이콘 (홈 화면 설치 정보) |

파일을 고치고 커밋하면 1~2분 뒤 GitHub Pages 주소에 반영돼요.
